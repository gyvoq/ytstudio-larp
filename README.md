# 🎬 YouTube Studio Clone — Channel Analytics

> The YouTube Studio analytics dashboard, rebuilt pixel by pixel in **a single HTML file**. Open it and it just works. No build, no install, no headaches.

## Why it's great

- **Looks identical to the original** — dark theme, embedded *YouTube Sans* font, navbar, sidebar and cards with the same spacing and colors.
- **Interactive chart** — views line chart with hover, vertical guide line and a custom tooltip (Chart.js).
- **Working date filter** — "Last 7 / 28 / 90 days, Lifetime, months and years" menu, just like Studio.
- **Zero project dependencies** — everything is inline (font, logo, CSS, JS). Only Chart.js is loaded from a CDN.
- **Perfect for mockups** — ideal for demos, tutorial videos, thumbnails, presentations and prototypes that need a "real" Studio.

## How to use

1. Download `yt-studio-identical-clone.html`
2. Double-click it
3. Done 🚀

> Tip: designed for **1280px** wide screens.

## Customize in seconds

| What | Where to edit |
|---|---|
| Channel photo / avatar | `src` of the avatar images |
| Channel name | `.channel-name` and `.channel-sub` |
| Numbers (views, watch time…) | text inside the metric cards |
| Chart curve | `seed` array in the `<script>` |
| Headline sentence | "Your channel got … views" |

## Stack

HTML · CSS · Vanilla JavaScript · [Chart.js 4](https://www.chartjs.org/)
